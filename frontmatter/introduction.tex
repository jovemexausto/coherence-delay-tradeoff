\section{Introduction}\label{sec:intro}

Modern deployed models operate in environments that are not merely noisy but
continuously changing. In recommender systems, adaptive control, and streaming
prediction, the system must estimate a time-varying state of the world from
finite data while continuing to act on that same world. Those actions can
change future observations, so the system faces a joint problem of inference,
staleness, and feedback. This paper focuses on the two resulting questions:
what finite memory can achieve under drift, and how to detect when apparent
coherence is being maintained by intervention rather than by adaptation.

A finite-memory
estimator benefits from using more observations, because more data reduces
statistical uncertainty. But larger windows also make the estimate older.
Under drift, that temporal lag produces model staleness: the data used to build
the estimate becomes progressively less representative of the present
environment. The central question is not whether one can estimate accurately in
a stationary regime, but how estimation accuracy is limited once memory and
non-stationarity are both unavoidable.

This tension admits a simple form. The total tracking error decomposes into a
variance term that falls with window size and a lag-bias term that rises with
the drift rate and the effective age of the data. Optimizing this trade-off
yields a cube-root law for the finite-memory estimator class analyzed here:
$\mathcal{E}_{\min} = \tfrac{3}{2}C_K^{2/3}\zeta^{1/3}$ with
$n^* = (C_K/\zeta)^{2/3}$. This law can be read as a limit on \emph{online
compression of a non-stationary process}: memory reduces variance, but it also
extends the interval over which a compressed model must remain valid while the
world keeps moving.

This finite-memory baseline is also the right reference point for evaluating
closed-loop diagnostics. In action-coupled systems, lower observed error need
not mean better estimation, because interventions can reduce error by steering
the environment toward a stale model. The coherence score $\Score$ measures the
apparent state-update bottleneck, while $\ScoreE$ is the main diagnostic for
the active masking regime because it discounts alignment purchased through
intervention rather than adaptation.

In closed-loop settings, raw tracking error is not always enough. A system may
appear well aligned with its environment because its actions are pushing the
environment toward a stale model rather than because the model remains current.
This is the phenomenon of \emph{feedback masking}. In the synthetic control
regime studied below, the same effect is called coercive masking. A useful
decomposition has three functional roles: a representation of the world
($\Pot$), an actuation rule ($\Act$), and an adaptation operator ($\Conv$).
It is motivated by action-effective tracking systems rather than by a claim
about information in general.

The decomposition yields two diagnostics. The first is the coherence score
$\Score$, a bottleneck-sensitive summary that combines model fidelity,
actuation reproducibility, and adaptation quality. The second is an
effort-corrected version, $\ScoreE$, designed for regimes where low observed
error may be purchased through intervention rather than through adaptation. The
distinction separates degradation from its cause and controls for
action-induced confounding.

\Cref{sec:tci} derives the coherence-delay trade-off and the finite-memory
cube-root law. \Cref{sec:necessity} shows that action-effective environments
require the update to depend on the current state, the most recent action, and
the incoming signal, which motivates the decomposition $(\Pot,\Act,\Conv)$.
\Cref{sec:tci,sec:ruffini} introduces $\Score$ and the effort-aware
$\ScoreE$. \Cref{sec:tgt} validates both claims: passive benchmarks test the
finite-memory baseline against generic drift alarms, while active and logged
benchmarks test whether effort-aware coherence can surface coercive masking.

The cube-root law holds for estimators with finite effective memory in the
sliding-window rate class analyzed here. The decomposition is motivated only
for \emph{action-effective} systems; passive observers are a genuine dyadic
boundary case. The stability results remain conditional on explicit ISS
hypotheses, with the Gaussian tracker serving as the constructive reference
instance, and the diagnostics describe failure modes rather than every possible
adaptive architecture.

\section{Mathematical Definitions}\label{sec:definitions}

\subsection{State Spaces and Information State}

\begin{definition}[State space]\label{def:statespace}
Let $S$ be a non-empty measurable space (the \emph{signal space}).
The \emph{information state space} $\Info$ is the space of all probability
measures on $S$ equipped with a metric $d_\Info$ compatible with weak
convergence.
Unless otherwise specified, $d_\Info$ denotes the $L^2$-Wasserstein
distance $W_2$.
\end{definition}

\begin{definition}[Potentiality]\label{def:potentiality}
The \emph{Potentiality} at time $t$ is a measurable map
\[
  \Pot(S,t) \in \Info,
\]
representing the system's current probability measure over possible world
states.
$\Pot$ is \emph{$\varepsilon$-coherent} at time $t$ if
$W_2\!\left(\Pot(S,t),\,\Pot^*(S,t)\right)\leq\varepsilon$,
where $\Pot^*(S,t)$ denotes the true marginal distribution of the
environment at time $t$.
\end{definition}

\begin{remark}[Computational realization of $W_2$]\label{rem:sinkhorn}
The $L^2$-Wasserstein distance $W_2$ is chosen as the metric on $\Info$
for its geometric faithfulness: unlike $f$-divergences such as KL
divergence, $W_2$ inherits the geometry of the underlying signal space $S$
and behaves well under spatial translations of the distribution support,
a desirable property when concept drift shifts the support of $\Pot^*$.
In high-dimensional signal spaces, exact computation of $W_2$ costs
$O(n^3\log n)$ via network-flow solvers.
For streaming applications requiring real-time $\Conv_t$ updates, the
entropic regularization of \citet{Cuturi2013} replaces $W_2$ with the
Sinkhorn divergence $S_\varepsilon$, computable in $O(n^2/\varepsilon^2)$
via parallelizable matrix-scaling iterations \citep{Altschuler2017}.
$S_\varepsilon$ converges to $W_2^2$ as $\varepsilon\to 0$ and breaks
the curse of dimensionality of raw $W_2$ at the cost of a bias proportional
to $\varepsilon$ \citep{GenevayEtAl2019}.
The theoretical results hold for $W_2$; their computational realization
in streaming contexts is demonstrated in the Gaussian-tracker experiments
(\cref{sec:tgt}; code at \cref{app:code_repository}).
\end{remark}

\begin{definition}[Actuation]\label{def:actuation}
The \emph{Actuation operator} is a measurable map
\[
  \Act_t\colon \Info \to \mathcal{O},
\]
where $\mathcal{O}$ is the output space (distinct from lowercase $o$,
which denotes a specific output element $o \in \mathcal{O}$).
$\Act_t$ is \emph{$\delta$-reproducible} if for any $p\in\Info$ and any two
executions $\omega,\omega'$,
$d_\mathcal{O}\!\left(\Act_t(p;\omega),\Act_t(p;\omega')\right)\leq\delta$.
A deterministic actuation is $0$-reproducible.
\end{definition}

\begin{definition}[Convergence operator]\label{def:convergence}
The \emph{Convergence operator} is a measurable map
\[
  \Conv_t\colon \Info \times \mathcal{O} \times S \to \Info,
\]
mapping the current information state, the most recent actuation, and an
incoming signal to an updated information state.
$\Conv_t$ is \emph{coherence-restoring} if there exist
$\beta\in\mathcal{KL}$ and $\gamma\in\mathcal{K}$ such that for all $t\geq 0$,
\[
  W_2\!\left(\Pot(S,t),\Pot^*(S,t)\right)
  \;\leq\;
  \beta\!\left(W_2\!\left(\Pot(S,0),\Pot^*(S,0)\right),t\right)
  \;+
  \gamma\!\left(\sup_{s\leq t}\norm{u(s)}\right),
\]
where $u(s)$ represents the environmental drift input at time $s$.
\end{definition}

\begin{definition}[Three-Role System]\label{def:tcccompliant}
An information system $\IS$ is a \emph{three-role system} if it is equipped
with all three operators $(\Pot,\Act,\Conv)$ satisfying
\cref{def:potentiality,def:actuation,def:convergence} respectively.
The composite information state is
\[
  \IS \coloneqq \bigl(\Pot(S,t),\Act_t,\Conv_t\bigr)
  \in \Info\times\mathcal{F}_\mathcal{O}\times\mathcal{F}_\Info.
\]
\end{definition}

\subsection{ISS Definitions}

\begin{definition}[Class $\mathcal{K}$, $\mathcal{KL}$]
A function $\gamma\colon\reals_{\geq 0}\to\reals_{\geq 0}$ is class
$\mathcal{K}$ if it is continuous, strictly increasing, and $\gamma(0)=0$.
A function $\beta\colon\reals_{\geq 0}^2\to\reals_{\geq 0}$ is class
$\mathcal{KL}$ if $\beta(\cdot,t)\in\mathcal{K}$ for each $t$ and
$\beta(r,\cdot)\to 0$ as $t\to\infty$ for each $r>0$.
\end{definition}

\begin{definition}[Input-to-State Stability]\label{def:iss}
A dynamical system $\dot x = f(x,u)$ is \emph{input-to-state stable} (ISS)
if there exist $\beta\in\mathcal{KL}$ and $\gamma\in\mathcal{K}$ such that
for every initial state $x(0)$, every essentially bounded input $u$, and all
$t\ge 0$,
\[
  \norm{x(t)} \le \beta(\norm{x(0)},t) + \gamma(\norm{u}_\infty).
\]
\end{definition}
