\begin{abstract}
Under drift, memory is both a statistical resource and a temporal liability:
retaining more past information reduces variance, but it also increases the age
of the evidence used to represent the present. The central question is therefore
not just how much to remember, but how long remembered evidence should remain
operationally valid.

We study this trade-off in a worst-case Wasserstein envelope. For the
finite-memory averaging class analyzed here, the tracking error decomposes into
a decreasing finite-sample term and an increasing staleness term. In the linear
staleness regime induced by the local $W_2$-Lipschitz path bound, this yields a
\textbf{cube-root horizon law}: the optimal memory scale obeys
$\boldsymbol{n^* \asymp (C_K/\zeta)^{2/3}}$, and the minimum tracking error
obeys $\boldsymbol{\mathcal{E}_{\min} \asymp C_K^{2/3}\zeta^{1/3}}$. In the
critical-window regime, we also prove a minimax lower bound, showing that this
finite-memory floor is structural rather than estimator-specific.

Empirically, Gaussian drift experiments recover the predicted $U$-curve and a
finite useful-memory optimum. Continuous-drift benchmarks expose a gap between
temporal validity and changepoint evidence; alternating-timescales benchmarks
show that contraction is easier than re-expansion; and horizon-misalignment
experiments show that stale memory can carry a nonlinear predictive cost.

The resulting picture is operational: temporal validity is not changepoint
evidence, and conservative horizon control can prevent stale memory from
persisting before a detector has enough evidence to alarm.

\end{abstract}
