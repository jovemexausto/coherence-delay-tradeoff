the main text. ELEC2 appears there as the representative case study; here we add
the Bikes counterpart and the paired summary table for both datasets.

The table shows the same mixed story across both streams: UMR can improve the
temporal-validity side of the comparison, but the precision effect is backend-
dependent and sometimes negative. That is why the full arena is supporting
evidence rather than the core argument.
