\section{Repository Guide}\label{app:repository_guide}

The repository contains provenance, regeneration scripts, and extended support
material that do not belong in the main text. This appendix records where the
principal artifacts are traced.

\paragraph{Artifact generation.}
The code for manuscript figures and tables is in
\path{code/useful_memory_horizon/}. Generated figures, tables, and CSV outputs
used by the manuscript are in \path{artifacts/}. The repository root
\path{README.md} records the regeneration commands.

\paragraph{Empirical provenance.}
The finite-memory diagnostics and the operational calibration tables are kept
out of the main text. The table sources are in
\path{artifacts/tables/gaussian/finite_sample_geometry.tex} and
\path{artifacts/tables/conceptual/carrier_layers.tex}, while the
corresponding appendix discussion is in \cref{app:finite_sample_geometry}.

\paragraph{Proof provenance.}
The theorem statements are in the main manuscript. Detailed derivations that are
part of the paper rather than the repository provenance layer are recorded in
\cref{app:proof_details}.
