\section{Code Repository}\label{app:code_repository}

All implementations are publicly available in the project repository
\citep{coherence_delay_repo}.

The repository contains:
\begin{itemize}[noitemsep]
  \item \texttt{experiments/run.py} --- single entry point for all experiment domains;
  \item \texttt{experiments/gaussian/} and \texttt{experiments/particle/} --- core experiment logic;
  \item \texttt{experiments/bikes/}, \texttt{experiments/elec2/}, and \texttt{experiments/kuairand/} --- domain-specific benchmarks;
  \item \texttt{REPRODUCIBILITY.md} --- setup and run instructions.
\end{itemize}

All experiments use \texttt{uv} for dependency management
(\texttt{uv sync}) and are reproducible with fixed random seeds as
specified in each script.
