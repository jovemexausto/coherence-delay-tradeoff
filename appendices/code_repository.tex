\section{Code Repository}\label{app:code_repository}

All implementations are publicly available in the project repository
\citep{parreira2026useful_memory_horizon}.

For reproducibility, the repository exposes a small set of generation scripts in
\texttt{code/} together with the corresponding outputs in \texttt{artifacts/}.

The repository contains:
\begin{itemize}[noitemsep]
  \item \texttt{code/generate\_gaussian.py} --- Gaussian $U$-curve and related support artifacts;
  \item \texttt{code/generate\_cuberoot\_adwin.py} --- continuous-drift benchmark figures and CSV summaries;
  \item \texttt{code/generate\_elec2.py} and \texttt{code/generate\_bikes.py} --- public-stream case-study artifacts;
  \item \texttt{code/generate\_temporal\_invalidity.py} --- controlled downstream benchmark;
  \item \texttt{code/generate\_tables.py} --- LaTeX table exports used by the manuscript;
  \item \texttt{code/generate\_zeta\_support.py}, \texttt{code/generate\_zeta\_self\_calibration.py}, and \texttt{code/generate\_finite\_sample\_geometry.py} --- appendix support artifacts;
  \item \texttt{artifacts/figures/}, \texttt{artifacts/csv/}, and \texttt{artifacts/tables/} --- canonical generated outputs consumed by the manuscript.
\end{itemize}

The experiment modules under \texttt{experiments/} and the shared horizon logic
under \texttt{drift/} remain as implementation support, but the
manuscript-facing pipeline is the one rooted in \texttt{code/} and
\texttt{artifacts/}. All runs use fixed random seeds as specified in the
generation scripts.
