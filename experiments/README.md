# Experiment Code

Python code for the experiments lives here.

The manuscript-facing modules are:

- `gaussian/` for law validation;
- `roughness_family/` for roughness-indexed scaling and horizon-misalignment artifacts;
- `invalidity_gap/` for detector-silent staleness and invalidity-gap artifacts;
- `cuberoot_adwin/` for legacy horizon geometry and transition benchmarks.

Other directories remain available as legacy or auxiliary harnesses.

See `../REPRODUCIBILITY.md` for setup and run commands.
